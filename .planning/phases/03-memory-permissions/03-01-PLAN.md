<task type="auto">
  <name>Task 2: engine.ts — MemoryEngine implementation</name>
  <files>apps/server/src/memory/engine.ts, apps/server/src/memory/goals.ts, apps/server/src/memory/disclosure.ts</files>
  <read_first>CONTRACTS.md §2 matrix, §6 interface, §5 schema (field_tags, disclosures)</read_first>
  <action>`createMemoryEngine(db, openai, io?): MemoryEngine`:
  - `ingest(userId, text, source)` → classifyFacts → insert memory_items rows (field_tags as JSON string) → return items.
  - `extractGoals(userId, taskId, text)` → llm → goal rows (status 'open').
  - `queryMemory(ownerUserId, requesterUserId, scope)`:
    a) load owner items; if requester===owner → candidates = all.
    b) else check trust_edges (owner→requester): trusted → candidates = public+network; stranger → public only.
    c) load canonical task_scopes by scope.taskId. Require scope.fields to be a subset of its allowed fields and validate requester/context through the trusted runtime. Match atomic facts by explicit tag intersection only; purpose is not a fallback. Reject missing or expanded scope.
    d) withheldCount = all owner facts considered minus returned facts, including classification and scope denials. Zero returned means denied; otherwise withheld > 0 means partial; otherwise released.
    e) insert one audit row with released IDs and counts. Build a DisclosureNotice with taskId, subchatId, ownerAgentId, releasedCount, withheldCount, and decision. Resolve authorized task/data-owner rooms and emit only to them, never globally. Missing io is allowed only in non-socket unit tests.
    f) return {items, withheldCount, disclosure} — withheld content never leaves.
  </action>
  <verify>unit tests on :memory: db — see Task 4 for the full matrix table</verify>
  <acceptance_criteria>
    - queryMemory return value never contains withheld item content (test greps response)
    - exactly one disclosures row per call (count query in test)
  </acceptance_criteria>
</task>
