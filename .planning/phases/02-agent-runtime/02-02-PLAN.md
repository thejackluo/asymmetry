  <files>apps/server/src/agents/tools.ts, apps/server/src/agents/subchats.ts</files>
  <read_first>CONTRACTS.md §6 tools list, §3 events, §5 subchat tables</read_first>
  <action>Implement tool handlers with trusted ctx containing acting agent, task owner, current subchat, and requesting peer; validate all model arguments before use.
  query_memory: owner is the receiving agent's human; requester is the initiating peer's human, not the receiver itself. Require canonical scope and supply taskId/subchatId server-side. Return authorized facts and counts only.
  open_subchat: include the initiating agent, validate the task and participant IDs, create pair/group rows, and emit metadata only to the task owner and participating owners. Do not use global socketsJoin.
  send_subchat_message: require acting-agent membership, reserve a capped conversation turn, persist once, emit only to authorized observers, and schedule other participants without blocking independent subchats.
  report_to_human: require the task owner's agent, persist and emit its summary, update that task, and close its resolved subchats.   <acceptance_criteria>
    - open_subchat writes subchats + participants rows; 'pair' vs 'group' correct
    - send_subchat_message emits subchat:message AND schedules recipient loop
    - report_to_human flips tasks.status and closes subchats
  </acceptance_criteria>
</task>
